Help & contact

A place to ask.

Minutes is maintained by Max Litwack, on GitHub as ashclient. Questions, bug reports and feature requests are welcome.

Report an issue ↗Get the latest release

For a useful bug report

Include your Minutes version, macOS version, what you expected and what happened. A redacted screenshot can help. For an AI issue, say which provider and detail level you used. You do not need to upload the original recording.

Keep private information private

GitHub issues are public. Do not post API keys, passwords, OAuth files, account tokens, private calendar information or recordings. For a privacy or security concern, describe the type of concern without the sensitive details and ask the maintainer for a private contact channel before sending more.

Common questions

Do I need Google or Notion?

No. You can use a blank note, record and keep notes locally. Integrations are optional.

Where is my data?

The app stores its local data in ~/Library/Application Support/Minutes. Credentials are in macOS Keychain. A copied or exported note may also exist in its destination service; see Privacy.

Will a public website finish Google setup?

The website provides product, privacy and terms information. Google OAuth registration, any required verification, and a deployed token service are separate setup steps. A static GitHub Pages site cannot run the token exchange.

What if generated notes are wrong?

Review the transcript and recording. You can edit the notes, regenerate them, or choose a different provider. Generation is not a substitute for checking important information.
