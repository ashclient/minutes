# Minutes 2.7.1

Native macOS meeting and lecture notes with Apple transcription, optional Apple Intelligence or OpenRouter, Google Calendar and Notion. Runs on macOS 14+; modern Apple speech needs macOS 26 on eligible hardware. Experimental Apple Intelligence generation currently requires macOS 27 and a ready system model.

## Download and updates

Install `Minutes-App.zip` from GitHub Releases and move Minutes.app to a writable Applications folder. Starting with 2.5, Minutes checks this repository's latest public GitHub release on launch, at most once every six hours. Use **Minutes → Check for updates…** or **Settings → General → Updates** for a manual check. New versions appear above Connections. **Install & relaunch** downloads, verifies and installs the update; it waits until recording, generation, pending draft choices and Notion sync are idle.

The updater accepts only this repository's release asset URL, checks GitHub's SHA-256 digest and archive paths, and verifies the bundle identity, version and code signature before replacement. A separate helper waits for the app to quit and keeps a backup during replacement. Notes and recordings in Application Support are outside the app bundle and are not replaced. Distribution uses an ad-hoc signature, not Developer ID notarization. Update trust comes from this GitHub repository and HTTPS; the checksum is not a separate publisher signature.

Every successful main-branch build publishes a release when the app version is new. Existing release assets are never overwritten. Bump `CFBundleShortVersionString` and `CFBundleVersion` in `Resources/Info.plist` before publishing an update. Fork pull requests do not publish releases.

## Recording and study notes

Choose a Google event or create a note, type your own notes, then record microphone or microphone plus computer audio. Approve macOS screen/system-audio capture for computer audio. No screen video is written. Use headphones to avoid capturing speakers twice through the microphone. The app remains usable while recording, and the draggable floating controls can collapse or dock at screen edges. Recordings and the transcript share an expandable source card.

Finish offers **Auto**, **Brief**, **Detailed**, or **Full detail**, plus **Outline**, **Cornell**, or **Q&A** formatting. Auto reads the source, consolidates its main concepts across the whole lecture, then writes concise, selective notes without a fixed word target. Brief targets about 300 words for the whole lecture; Detailed about 900. Local generation rewrites/selects meaningfully instead of clipping lines to force a count; complete notes can exceed those approximate targets. Full detail retains broader explanations and examples. Outline follows personal college notes: short plain explanations mixed with lists, meaningful topic/subtopic headings, nested details, numbered examples and standalone formulas. It adapts to business definitions/comparisons, accounting scenarios/account effects, and math variables/units/worked steps. Auto preserves meaningful definitions and complete selected examples through the evidence passes, rather than reducing everything to keyword inventories. Apple evidence extraction is internal and retained in a ledger. A title/ID plan groups related concepts without replacing their evidence; missing planner IDs are restored. Topic writers read every retained evidence batch into one coordinated document, then optional editors check complete topics using original source excerpts. There is no recursive compression of all lecture facts into one small global extract. Settings exposes 1–4 independent model sessions (default 2) and a collaborative editing toggle. These requests share local hardware and may be queued by macOS; no parallel speedup is promised. Active worker chips and topic markers correspond to actual jobs. Topics too large for an additional check are preserved unchanged instead of truncated. Local responses are never line-clipped to a word count. Incomplete or severely reduced editor replies are rejected and the last complete topic is retained. Topic output has one bounded repair attempt for structural incompleteness. Guards detect dangling endings, unbalanced formatting/math and recognizable fabricated qualitative equations; they do not prove factual correctness. Text streams as a live draft. Grapheme-aware middle edits preserve the unchanged suffix, animate removal and insertion, and show briefly struck-through deletions at the affected location. Reduce Motion applies edits immediately. Cancelling a draft offers keep-partial or revert; previous saved notes stay intact until successful replacement or an explicit keep choice.

Apple's system model has a small context window, so long lectures require multiple requests. Generation can omit or misinterpret information, including numbers; the full transcript and audio remain available. No measured tokens-per-second rate is promised. Minutes never silently switches Apple generation to cloud AI. OpenRouter defaults to the pinned `nvidia/nemotron-3.5-lightning:free` model. General settings loads a live free-model catalog and includes an editable model ID and Reset; the unavailable 2.6.1 default migrates automatically. non-free model IDs may incur account charges. Free endpoint quotas and capacity still apply. Only text is sent, not recordings.

## Google Calendar

Direct read-only Google Calendar access supplies Day, Week, Month and Agenda layouts. Clicking an event opens its meeting note. A Google Desktop OAuth client must be imported once: enable Calendar API, configure the consent screen/test user, create a Desktop client and import its JSON in Connections. PKCE and a local loopback callback are used. Credentials/tokens stay in macOS Keychain. There is no iCloud/EventKit integration or calendar-write scope.

## Notion

Connect a Notion personal token or internal connection in Connections, then choose a destination. Personal tokens/public user connections can create Private top-level pages; internal connections need a parent page shared with that connection. On finish choose local-only, a new page, the linked page or an existing page. Existing-page mode does not change the destination title. Meeting occurrences retain separate local notes and page IDs; normal retries reuse the saved page.

Sync writes native headings, nested bullets/numbered steps, formatted rich text and equations. Only recorded Minutes-owned block IDs are replaced. Before replacement, sync checks whether those blocks or their descendants were edited after the previous sync. A conflict preserves the Notion version and offers **Preserve edits & add copy**; that choice leaves the old section and appends a fresh local copy. Already-deleted owned blocks no longer trap cleanup in a retry loop. This is conflict protection, not bidirectional editing: Notion changes are not imported into the local summary. Concurrent edits during the upload and a lost create/append response can still leave duplicates/orphans; Notion supplies no idempotency key for these calls.

## Data, build and verification

Audio stays in `~/Library/Application Support/Minutes/Audio`; copy the entire Minutes support folder while closed for an audio-inclusive backup. JSON backups do not include audio. Quit saves text and closes capture without waiting for AI.

Build on a Mac with `bash build.command`. `MINUTES_RUN_TESTS=1` requires full Xcode. `MINUTES_UNIVERSAL=1` builds Apple Silicon and Intel, including the update helper. CI runs tests, verifies signatures/architectures, exercises the real helper against disposable app copies, and captures native UI previews. Live microphone/system-audio performance, Apple model quality/speed and account workflows still require real hardware/account testing.

Keychain access: Google status checks read metadata without requesting credential bytes. Successful credential reads are shared in process memory, including concurrent requests; refreshed or disconnected credentials update that cache after a successful Keychain write. Denied reads briefly suppress duplicate requests. Secrets remain in Keychain between launches. Ad-hoc release signatures can still require renewed authorization after an update; consistent certificate-based signing is needed for identity continuity.

NVIDIA API is available in General settings alongside Apple Intelligence and OpenRouter. Its default model is `nvidia/nemotron-3.5-lightning-30b-a3b`, using NVIDIA’s hosted endpoint directly, with thinking disabled for note writing. Paste a NVIDIA API key; Connect validates it using a small synthetic connection test before saving it to the separate `nvidia` Keychain item. No audio is uploaded. NVIDIA account limits apply; there is no automatic fallback to another service. Both cloud providers read up to 180,000 characters per source chunk and process draft/check requests sequentially. Their large default context windows let most lectures fit one chunk, avoiding an extra consolidation request. Custom model IDs must support the input size. Both request real SSE streaming Markdown and display throttled live updates through the existing smooth reveal. Cloud requests display a moving indeterminate activity bar; completed passes, rather than unknown output length, drive any determinate progress. SSE framing handles heartbeat comments, multi-line data, split UTF-8, usage frames, reasoning fields, errors, truncation and missing completion markers. Compatible servers that ignore streaming can still return a normal JSON envelope; it appears when complete. Cloud replies accept supported JSON shapes or usable Markdown; unreadable output gets one bounded formatting retry. Connection tests accept short successful replies. Actual provider quality, streaming behavior and access require a user API key.
